# github-developer-analyzer
A web app that analyzes GitHub user profiles, repositories, and developer statistics using the GitHub API.

# GitHub Profile Comparator

A modern GitHub profile comparison dashboard built with vanilla JavaScript, HTML, and CSS.

Compare two GitHub users based on:

- ⭐ Total Stars
- 👥 Followers
- 📦 Public Repositories
- 🏆 Top Repository
- 💻 Most Used Languages
- 📊 Overall Score

---

# 🚀 Run Locally

## 1. Clone the repository

```bash
git clone <your-repo-url>
cd <your-project-folder>
```

## 2. Start a local server

VS Code Live Server

- Install the **Live Server** extension
- Right click `index.html`
- Click **Open with Live Server**
